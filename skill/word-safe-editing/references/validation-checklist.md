# Validation checklist

Read this checklist for Full Path edits or before delivering a publication-sensitive document.

- Confirm the requested change and target path.
- Preserve a recoverable original.
- Run structural and content-boundary checks.
- Review affected and surrounding pages.
- Open in Microsoft Word without repair or conversion alerts.
- Save in Microsoft Word without failure alerts.
- Re-check key invariants after Word saves.
- Remove temporary backups, previews, logs, and test outputs.
